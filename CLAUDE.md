# Tender for Frigate

SwiftUI app for iOS, iPadOS and Mac Catalyst (scheme `Frigate`). The strings are in English, with
translations in `Frigate/Localizable.xcstrings`.

- Before building or changing UI, read [docs/UX.md](docs/UX.md) and follow it.
- Follow Frigate's web UI (source in `../frigate`) for names, flows and API use.
